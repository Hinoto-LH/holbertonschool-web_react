# holbertonschool-web_react

Projet realise dans le cadre de la formation Holberton School.
Ce depot regroupe les differents modules du cursus React et TypeScript.

---

## Modules

### TypeScript

Introduction a TypeScript et a ses fonctionnalites avancees.

| Tache | Description |
|-------|-------------|
| task_0 | Interface Student, tableau d'etudiants et rendu DOM |
| task_1 | Interface Teacher avec proprietes readonly, optionnelles et index signature. Interface Directors etendant Teacher. Fonction printTeacher. Classe StudentClass |
| task_2 | Classes Director et Teacher implementant des interfaces. Fonction createEmployee, type predicate isDirector, executeWork. String literal type Subjects et fonction teachClass |
| task_3 | Types RowID et RowElement, fichier de declaration ambient crud.d.ts pour une bibliotheque JavaScript externe |
| task_4 | Namespaces TypeScript avec declaration merging. Classes Cpp, React et Java dans le namespace Subjects |
| task_5 | Typage nominal avec branded types. Interfaces MajorCredits et MinorCredits, fonctions sumMajorCredits et sumMinorCredits |
